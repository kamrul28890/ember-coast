# Generated self-play evidence

- `tuning.json`: selected weights, fixed prior, all six candidates, seat-rotated training outcomes.
- `benchmark.json`: untouched seed-prefix evaluation against fixed prior bots, without search.
- `search-evaluation.json`: complete matches at the browser's production search budget.
- `*-before-calibration.json`, `search-pilot.json`: earlier diagnostic runs. These are not the final policy's results.

The files contain synthetic games generated by this repository. They are not human replays. Training on a local simulator and obtaining wins against a baseline does not establish human-level play. Read `docs/EVALUATION.md` for interpretation, limitations, and reproduction.
